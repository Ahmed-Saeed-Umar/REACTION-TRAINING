# REACTION TRAINING 🎯

Reaction Training is a **Java Swing–based GUI game** designed to improve your **reaction time and impulse control** through a collection of fast-paced mini games.

The games require you to respond in **milliseconds**, pushing your focus, speed, and decision-making under pressure.

---

## 🧠 What is Reaction Training?

Reaction Training is a desktop application that challenges players with multiple exercises that test:
- ⚡ Reaction speed
- 🎮 Impulse control
- 🧩 Focus and timing
- ⏱️ Split-second decision making

Each game is designed to train your brain to react faster and more accurately over time.

---

## 🎮 Features

- Multiple reaction-based mini games
- Millisecond-level response challenges
- Java Swing GUI (no external frameworks)
- Simple and intuitive user interface
- Designed to progressively test your limits

---

## 🛠️ Built With

- **Java**
- **Java Swing (GUI)**
- Object-Oriented Programming principles
